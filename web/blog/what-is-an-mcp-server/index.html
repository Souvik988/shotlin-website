What is an MCP server — and should your SaaS ship one?

MCP lets AI assistants use your product's tools and data. What it is in plain words, why SaaS teams should care, and how to build one safely.

Key takeaways

  • MCP (Model Context Protocol) is an open standard for connecting AI assistants to tools and data.
  • An MCP server lets your customers use your product from inside their AI assistant.
  • Scope every tool to the user's permissions and log every action.
  • Ask for human confirmation before anything destructive.

AI assistants are moving from answering questions to doing work. The Model Context Protocol (MCP) is the open standard that makes this possible: a consistent way for assistants to discover and use tools and data from other products.

How it works, in plain words

Your MCP server describes what your product can do — tools such as "create invoice" or "deploy app" — and what it can read. An assistant discovers those tools and calls them on the user's behalf, within the permissions you set.

Why SaaS teams should care

More of your customers' work is happening inside AI assistants. An MCP server lets them use your product from there, instead of switching tabs — which keeps your product in the loop.

What we built

Our own platform, Opslin, has a permissioned MCP beta so AI assistants can run deployments — with the same access rules a human user has.

Getting it right

  • Scope every tool to the signed-in user's permissions.
  • Log every call so actions are auditable.
  • Rate-limit and validate inputs like any public API.
  • Require a human confirmation for destructive actions.

Frequently asked questions

What does MCP stand for?

Model Context Protocol — an open standard for connecting AI assistants to tools and data.

Is an MCP server secure?

It can be, when every tool is scoped to the user's permissions, actions are logged and risky actions need confirmation.

Can Shotlin build an MCP server for my product?

Yes. We design the tools, permissions and hosting, and test them with real AI assistants.
